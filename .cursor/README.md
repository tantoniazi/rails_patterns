# Cursor Agents – Rails Senior Study

Agentes especializados alinhados aos 14 módulos de `docs/`. Cada agente usa o material correspondente como referência principal para entrevistas sênior Rails.

## Como usar

1. Abra o agente desejado no Cursor (Custom Agents / `@agent`).
2. Peça explicações, exercícios, revisão de código ou simulação de entrevista.
3. O agente consulta `docs/` e o código em `app/` quando relevante.
